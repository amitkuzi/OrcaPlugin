# OrcaPlugin

A collection of OrcaSlicer plug-ins maintained by [Amit Kuzi](https://amitkuzi.github.io/).

- [CentauriSync](CentauriSync/README.md) reads first-generation Centauri Carbon CANVAS tray data for OrcaSlicer's filament sync. Version 0.2.0 is a prerelease dated 2026-11-21. Mock-printer and fixture tests passed; real OrcaSlicer and printer acceptance are not yet validated. It does not print or upload.

License: [AGPL-3.0-only](LICENSE). See [attribution](NOTICE.md).

Each plug-in keeps its own source, tests and packaging instructions. No printer settings or generated local release artifacts belong in this repository.
